<p>Why a single project: nothing under <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>src/</span></span></code></span> needs declaration emission
(the bundler is electron-vite), and the renderer, preload and main
processes share enough types that splitting them into project
references would mostly add ceremony. A single <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>--noEmit</span></span></code></span> project keeps
the wiring minimal without giving up strict mode.</p>
<p>Relevant settings (<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>tsconfig.base.json</span></span></code></span>):</p>
<ul>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>strict: true</span></span></code></span> (every strict flag on)</li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>noUncheckedIndexedAccess: false</span></span></code></span> — too disruptive given existing
index-access patterns (tabs, listToc)</li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>exactOptionalPropertyTypes: false</span></span></code></span> — kept off to keep the buffered-state
restore path (which carries optional fields through JSON serialization)
tolerant of <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>undefined</span></span></code></span> ≡ "key not present"</li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>allowJs: false, checkJs: false</span></span></code></span> — every directory under <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>src/</span></span></code></span> is
now <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>.ts</span></span></code></span> except <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>src/muya/</span></span></code></span>, which the rest of the tree reaches
through the ambient declarations in <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>src/types/muya.d.ts</span></span></code></span></li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>noEmit: true</span></span></code></span> — vue-tsc only type-checks; electron-vite handles the
actual bundling</li>
</ul>

<h2 id="strict-mode-landmines">Strict-mode landmines<a class="anchor" aria-hidden tabindex="-1" href="#strict-mode-landmines">#</a></h2>
<ul>
<li><strong><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>strictPropertyInitialization</span></span></code></span></strong> — class fields must be initialized
in the constructor or marked with <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>!:</span></span></code></span> (definite-assignment assertion).
Prefer initialization; reach for <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>!:</span></span></code></span> only where the runtime guarantees
the field is set before any access.</li>
<li><strong><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>useUnknownInCatchVariables</span></span></code></span></strong> — <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>catch (err)</span></span></code></span> gives <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>err: unknown</span></span></code></span>.
Narrow before using: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>err instanceof Error ? err.message : String(err)</span></span></code></span>.</li>
<li><strong><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>noImplicitAny</span></span></code></span></strong> — every callback parameter needs a type. For
iterators (<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>tabs.find(t => ...)</span></span></code></span>), TS infers from the element type.</li>
<li><strong>Event handler unions</strong> — Electron's <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>BrowserWindow.on</span></span></code></span> is heavily
overloaded; passing a union of event names (<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>'maximize'|'unmaximize'|...</span></span></code></span>)
can require a cast through <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>any</span></span></code></span>.</li>
</ul>
