<h2 id="打开文件和文件夹">打开文件和文件夹<a class="anchor" aria-hidden tabindex="-1" href="#打开文件和文件夹">#</a></h2>
<p>首次启动时可使用 <strong>Recent Documents（最近文档）</strong>、<strong>New File（新建文件）</strong> 或 <strong>Open File（打开文件）</strong>。通过文件菜单打开本地 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>.md</span></span></code></span> / <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>.markdown</span></span></code></span> 文件，或者打开一个包含多个 Markdown 文件的文件夹。</p>
<p>打开文件夹后，左侧 <strong>Files（文件）</strong> 显示目录树；<strong>Search（搜索）</strong> 用来查找文件夹内容；<strong>Outline（大纲）</strong> 显示当前文档的标题；<strong>More → Document Info（文档信息）</strong> 提供反向链接和本地历史。</p>
<p><img src="/docs/assets/inkiva-interface.png" alt="Windows v0.6.0 英文界面的文档、标签页与大纲侧栏实机截图"></p>
<p>命令搜索请使用 <strong>View → Command Palette</strong>；不要寻找旧版顶部搜索框。</p>
<p><img src="/docs/assets/inkiva-command-palette.png" alt="Windows v0.6.0 命令面板实机截图"></p>
<h2 id="编辑与保存">编辑与保存<a class="anchor" aria-hidden tabindex="-1" href="#编辑与保存">#</a></h2>
<p>所见即所得编辑区直接接受文字输入。按 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>/</span></span></code></span> 可在空段落中打开快速插入菜单；<strong>View → Source Code Mode</strong> 用来查看或修改 Markdown 原始文本。普通点击 Markdown 链接只定位光标，不会直接跳转。</p>
<p>Inkiva 提供自动保存和恢复保护，但退出应用、恢复旧版本或将文件移动到其他设备前，仍建议确认保存状态并保留独立备份。</p>
<h2 id="标题导航和文档信息">标题导航和文档信息<a class="anchor" aria-hidden tabindex="-1" href="#标题导航和文档信息">#</a></h2>
<p><strong>Outline</strong> 的键盘焦点属于大纲树容器，不是虚拟化的单个标题行。实测 360 个标题时，End 和上方向键只改变大纲焦点，不移动正文；按 Enter 才跳转。</p>
<p><img src="/docs/assets/inkiva-outline-keyboard.png" alt="360 标题大纲定位末尾、正文不跳转"></p>
<p><img src="/docs/assets/inkiva-outline-activated.png" alt="按 Enter 跳转到目标标题"></p>
<p><strong>More → Document Info → Backlinks</strong> 会显示指向当前文档的反向链接，包括已保存、但没有打开为标签页的工作区 Markdown 文件。</p>
<p>同一面板的断链检测可以识别工作区内找不到目标文件的相对 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>.md</span></span></code></span> / <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>.markdown</span></span></code></span> 链接。点击断链条目可定位源链接（无独立的 Locate 文字按钮，其辅助功能名称为 <strong>Locate source occurrence</strong>）；点击可见的 <strong>Repair</strong> 按钮后打开 <strong>Insert link</strong> 对话框。确认前不会自动替换，选择 <strong>Cancel</strong> 不修改原文档。</p>
<p><img src="/docs/assets/inkiva-broken-link-repair.png" alt="Windows v0.6.0 英文界面的断链 Repair 对话框实机截图"></p>
<p>无法读取的文件与确定不存在的文件应区别对待。</p>
<h2 id="文件链接">文件链接<a class="anchor" aria-hidden tabindex="-1" href="#文件链接">#</a></h2>
<p>选中文字后按 Windows <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Ctrl+K</span></span></code></span> 或 macOS <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Command+K</span></span></code></span> 打开链接编辑器。工作区中的 Markdown 文件会作为候选，保存的是标准相对链接，例如 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>[说明](./guide.md)</span></span></code></span>。新建且未保存的文档应先保存，再生成相对文件链接。</p>
<p>跳转链接使用 Windows <strong>Ctrl+单击</strong>、macOS <strong>Command+单击</strong>，或链接工具提供的显式跳转操作。</p>
