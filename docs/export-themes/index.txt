<h2 id="install-a-theme">Install a theme<a class="anchor" aria-hidden tabindex="-1" href="#install-a-theme">#</a></h2>
<p>You can install a theme by copying the <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>.css</span></span></code></span> file to <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>themes/export/</span></span></code></span> directory inside the <a href="/docs/application-data-directory" class="link">application data directory</a> location but you may need to restart Inkiva to detect the theme.</p>
<h2 id="create-a-theme">Create a theme<a class="anchor" aria-hidden tabindex="-1" href="#create-a-theme">#</a></h2>
<p>Inkiva use the GitHub theme as basic style that is always available. A custom theme can add additional styles but have to overwrite the GitHub style to make changes such as font family or the underling for heading. You can see all predefined styles <a href="https://github.com/sindresorhus/github-markdown-css/blob/gh-pages/github-markdown.css" class="link">here</a>. An example for custom themes can be found <a href="https://github.com/Bulls1986/Inkiva/blob/develop/src/renderer/assets/themes/export/academic.theme.css" class="link">here</a> and <a href="https://github.com/Bulls1986/Inkiva/blob/develop/src/renderer/assets/themes/export/liber.theme.css" class="link">here</a>.</p>
