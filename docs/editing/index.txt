<h2 id="text-manipulation">Text manipulation<a class="anchor" aria-hidden tabindex="-1" href="#text-manipulation">#</a></h2>
<p>Inkiva shows you formatted text in realtime, where you can simply write and edit text, as well as use markdown syntax. To improve your writing efficiency there are a lot of key bindings for better text manipulation. In the preferences you can control the editor settings such as font settings, autocompletion and line width.</p>
<h2 id="selections">Selections<a class="anchor" aria-hidden tabindex="-1" href="#selections">#</a></h2>
<p>You can select text with your mouse cursor, double click on a word or use the keyboard <kbd>Shift</kbd>+<kbd>Arrow Keys</kbd>.</p>
<p><strong>Format overlay:</strong></p>
<p>The format overlay is a pop-up that automatically appears when you're selecting text. You can easily transform text and inline markdown, and remove formatting.</p>
<p><img src="/docs/assets/inkiva-format-popup.png" alt=""></p>
<ul>
<li>Bold</li>
<li>Italics</li>
<li>Underline</li>
<li>Strikethrough</li>
<li>Inline code</li>
<li>Inline math formulas</li>
<li>Create link</li>
<li>Create image</li>
<li>Remove formatting</li>
</ul>
<p>Further overlays are available for emojis, links, images and tables.</p>
<h2 id="deleting">Deleting<a class="anchor" aria-hidden tabindex="-1" href="#deleting">#</a></h2>
<p>Do you want to delete headings, lists or tables? Just select the area and press backspace.</p>
<h2 id="brackets-and-quotes-autocompletion">Brackets and quotes autocompletion<a class="anchor" aria-hidden tabindex="-1" href="#brackets-and-quotes-autocompletion">#</a></h2>
<p>You can configure Inkiva to autocomplete markdown syntax, brackets and quotes. By default <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>()</span></span></code></span>, <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>[]</span></span></code></span>, <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>{}</span></span></code></span>, <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>**</span></span></code></span>, <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>__</span></span></code></span>, <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>$$</span></span></code></span>, <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>""</span></span></code></span> and <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>''</span></span></code></span> are completed when the first character is typed.</p>
<h2 id="links">Links<a class="anchor" aria-hidden tabindex="-1" href="#links">#</a></h2>
<p>Links are displayed by default as normal text, but if you click on a link it is shown as a markdown link with title and URL, as shown below:</p>
<p><img src="/docs/assets/inkiva-link-preview.png" alt=""></p>
<h2 id="formatting">Formatting<a class="anchor" aria-hidden tabindex="-1" href="#formatting">#</a></h2>
<p>Inkiva will automatically format your markdown document according CommonMark and GitHub Flavored Markdown specification. Some settings, such as list indentation, can be controlled via preferences.</p>
<h2 id="editing-features">Editing features<a class="anchor" aria-hidden tabindex="-1" href="#editing-features">#</a></h2>
<h4 id="quick-insert">Quick insert<a class="anchor" aria-hidden tabindex="-1" href="#quick-insert">#</a></h4>
<p>When you start a new line, just type / to access a pop-up with all available markdown features. At this point, you can choose an entry and the line is transformed into the selected attribute.</p>
<p><img src="/docs/assets/inkiva-quick-insert.png" alt=""></p>
<h4 id="line-transformer">Line transformer<a class="anchor" aria-hidden tabindex="-1" href="#line-transformer">#</a></h4>
<p>You can transform a line into another type by clicking on the highlighted icon in the image below and select <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Turn Into</span></span></code></span>. Furthermore, you can duplicate the selected line, create a paragraph above the selected line or delete the line.</p>
<p><img src="/docs/assets/inkiva-line-transformer.png" alt=""></p>
<h4 id="table-tools">Table tools<a class="anchor" aria-hidden tabindex="-1" href="#table-tools">#</a></h4>
<p>It's sometimes hard to write and manage tables in markdown. In Inkiva you can press <kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> to get a table dialog and create a table with variable row and column count. Both row and column count can be changed via the table tools (first icon above the table) later if necessary. You can use all inline styles in a table cell and align the text via table tools at the top of the table.</p>
<p><strong>Insert and delete rows and columns:</strong></p>
<p>You can insert or delete a new row or column by clicking on an existing cell and clicking on the menu on the right side for rows or bottom for columns.</p>
<p><img src="/docs/assets/inkiva-table_drag_drop.png" alt=""></p>
<p><strong>Move table cells:</strong></p>
<p>You can simply move a row or column by clicking on the cell menu (like above) and dragging it by holding your left mouse button like this:</p>
<p><img src="/docs/assets/inkiva-table-gif.gif" alt=""></p>
<h4 id="image-tools">Image tools<a class="anchor" aria-hidden tabindex="-1" href="#image-tools">#</a></h4>
<p><img src="/docs/assets/inkiva-image-viewer.png" alt=""></p>
<p>Inkiva provides an image viewer and a pop-up to select and label images. You can resize any image using your mouse cursor; changes are applied in realtime. By clicking on an image or writing <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>![]()</span></span></code></span> a pop-up automatically appears that allows you to select an image from disk, or paste a path or URL. Images can be automatically uploaded to cloud, or moved to a relative or absolute path on your local disk. Even pasting images that are not located on disk is supported and these images are stored in the background. In addition, you can control the image alignment whether inline, left, centered or right.</p>
<p><img src="/docs/assets/inkiva-image-popup.png" alt=""></p>
<h4 id="emoji-picker">Emoji picker<a class="anchor" aria-hidden tabindex="-1" href="#emoji-picker">#</a></h4>
<p>Instantly add emojis to your markdown document without long searches. While typing, the application automatically refreshes the list of available emojis.</p>
<p><img src="/docs/assets/inkiva-emoji-picker.png" alt=""></p>
<h4 id="focus-mode">Focus mode<a class="anchor" aria-hidden tabindex="-1" href="#focus-mode">#</a></h4>
<p><img src="/docs/assets/inkiva-focus-mode.png" alt=""></p>
<p>The focus mode will help you to focus on the currently line only by fading out other lines. To activate the focus mode, simply press <kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd>.</p>
<h4 id="typewriter-mode">Typewriter mode<a class="anchor" aria-hidden tabindex="-1" href="#typewriter-mode">#</a></h4>
<p>In typewriter mode, the cursor is always keep in the middle of the editor.</p>
<h2 id="file-encoding">File encoding<a class="anchor" aria-hidden tabindex="-1" href="#file-encoding">#</a></h2>
<p>Inkiva tries to automatically detect the encoding and byte-order mark (BOM) of a file upon opening it. The default encoding is UTF-8 that should support all needed characters but can be changed in settings. You can disable automatic encoding detection; however, the application will then assume that all files are UTF-8 encoded. The currently used encoding can be shown and changed via command palette.</p>
<h2 id="line-endings">Line endings<a class="anchor" aria-hidden tabindex="-1" href="#line-endings">#</a></h2>
<p>Inkiva automatically analyzes each file and detects the used line ending and can be changed via command palette too.</p>
<h2 id="find-and-replace">Find and replace<a class="anchor" aria-hidden tabindex="-1" href="#find-and-replace">#</a></h2>
<p><strong>Inside the editor:</strong></p>
<p>To quickly find a keyword in your document press <kbd>CmdOrCtrl</kbd>+<kbd>F</kbd> to open the search pop-up. Now you can search for text or replace the given keyword.</p>
<p><strong>Search in opened folder:</strong></p>
<p>Inkiva provides a built-in filesystem explorer (tree view) with a fast file searcher. Type a keyword in the search bar and select the needed options like regex or case-insensitive search. That's all!
