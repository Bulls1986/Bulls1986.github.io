图片上传器配置#

Inkiva 支持将 PicGo 作为可选外部图片上传工具。PicGo 可将图片上传至你自行配置的云存储目标；它并不是 Inkiva 账号或内置云同步服务。

  1. 根据 PicGo 官方文档 安装并配置 PicGo。
  2. 在 Inkiva 的 Preferences → Image 中指定 PicGo 可执行文件。
  3. 将图片插入动作设置为 upload，或从图片工具中按需上传。

不使用上传功能时可保留本地图片文件与标准 Markdown 路径。参阅图片处理。
