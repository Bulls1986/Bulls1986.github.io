<h2 id="0170">0.17.0<a class="anchor" aria-hidden tabindex="-1" href="#0170">#</a></h2>
<p>Inkiva is now Inkiva! We'd like to thank all contributors and users that have been using Inkiva and worked on this release.</p>
<p><strong>:warning:Breaking Changes:</strong></p>
<ul>
<li>Changed multiple default key bindings.</li>
<li>Changed key binding handling: all key bindings are now mapped to the corresponding US key bindings. E.g. <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Ctrl+Shift+7</span></span></code></span> on a German keyboard will now produce <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Ctrl+/</span></span></code></span> because <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Shift+7</span></span></code></span> is equivalent to <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>/</span></span></code></span>.</li>
<li>Image uploader: SM.MS was removed, GitHub uploader is deprecated and will be replaced by PicGo in our next release.</li>
</ul>
<p><strong>:cactus:Feature</strong></p>
<ul>
<li>Added support for image path variables.</li>
<li>Added command-line image uploader and reworked settings.</li>
<li>Added regular expression group replacement to searcher.</li>
<li>Added PlantUML diagram support.</li>
<li>Added support for chemical equations in math mode.</li>
<li>Added automatic call to search for find-in-file when the pane is opened.</li>
<li>Open local non-markdown files in default application.</li>
<li>Added support to use all menu entries for key binding.</li>
<li>Added window zoom via default mouse event.</li>
<li>Zoom level is now restored on startup.</li>
<li>Added PicGo to upload images.</li>
<li>Ability to invalidate image cache on demand.</li>
<li>Added settings page to configure key bindings.</li>
</ul>
<p><strong>:butterfly:Optimization</strong></p>
<ul>
<li>Improved inline markdown autocomplete support.</li>
<li>Improved preference design.</li>
<li>Relative image paths are now converted to forward slashes on Windows for better compatibility.</li>
<li>Center sidebar image when no search results are available.</li>
<li>Updated emoji database.</li>
<li>Improved sidebar file handling UX by providing more error messages.</li>
</ul>
<p><strong>:beetle:Bug fix</strong></p>
<ul>
<li>Fixed an issue with code block cursor positioning.</li>
<li>Fixed invalid mermaid diagram representation when exporting as PDF.</li>
<li>Fixed rendering issue with LaTeX formulas</li>
<li>Fixed an issue that may caused editor flickering while pressing <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Enter</span></span></code></span>.</li>
<li>Fixed Table of Contents sidebar display issue.</li>
<li>Fixed editor overflow when the sidbar is open.</li>
<li>Fixed a crash that occurred due to a bug in the markdown footnote parser.</li>
<li>Fixed issue with shortcuts that included <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Alt</span></span></code></span>.</li>
<li>Fixed multiple issues on non-US keyboards.</li>
<li>Normalized source-code editor cursor.</li>
<li>Fixed preference scaling issue and added missing scrollbar.</li>
<li>Fixed a rendering issue when multiple elements were selected via keyboard.</li>
<li>Fixed preference migrations were always executed on start-up.</li>
<li>Fixed scrolling and search match positing with high DPI scaling.</li>
<li>Fixed slow startup on Windows due to a blocking call.</li>
<li>Fixed an issue that caused the paste handler to insert only HTML content because if HTML rendering was disabled.</li>
<li>Fixed file rename with editor dialog.</li>
<li>Fixed URL open handler when clicking a link in the editor.</li>
<li>Fixed an issue that prevented to unindent a list item.</li>
<li>Fixed multiple XSS issues on language selector and data input.</li>
<li>Fixed a bug that HTML was rendered in preview mode even it was disabled in settings.</li>
<li>HTML character encoding is now supported in code blocks.</li>
</ul>
