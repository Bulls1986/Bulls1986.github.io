19:T15ae,<h2 id="v060--document-navigation-and-asset-experience">v0.6.0 — Document navigation and asset experience<a class="anchor" aria-hidden tabindex="-1" href="#v060--document-navigation-and-asset-experience">#</a></h2>
<p>Published 2026-10-29.</p>
<p><strong>Features</strong></p>
<ul>
<li>Workspace-aware relative Markdown link indexing and backlinks, including navigation to the source occurrence.</li>
<li>Link candidate completion and deliberate cross-document or heading navigation.</li>
<li>Broken local-link diagnostics with explicit, guarded repair rather than silent source rewrites.</li>
<li>Safer rename/move reference repair with conflict handling and recovery.</li>
<li>Image insertion and paste improvements, safer relative paths, relinking and missing-resource recovery.</li>
<li>Outline keyboard/focus correctness, table regression fixes and workspace lifecycle hardening.</li>
</ul>
<p><strong>Compatibility and release</strong></p>
<ul>
<li>Markdown files remain the source of truth. No proprietary wiki syntax or separate document database is introduced.</li>
<li>Official desktop packages are published for Windows x64 and macOS Intel/Apple Silicon.</li>
<li>macOS packages are unsigned and not notarized. Gatekeeper may require an explicit first-launch approval; follow the instructions on the <a href="https://github.com/Bulls1986/Inkiva/releases/tag/v0.6.0" class="link">v0.6.0 release page</a>.</li>
</ul>
<h2 id="v050--reliability-and-workspace-experience">v0.5.0 — Reliability and workspace experience<a class="anchor" aria-hidden tabindex="-1" href="#v050--reliability-and-workspace-experience">#</a></h2>
<p>Published 2026-10-08.</p>
<ul>
<li>Added crash recovery for untitled drafts and safer Local History restore.</li>
<li>Improved workspace/session restore, file identity across rename/move, and recovery of unsaved work.</li>
<li>Improved input/IME continuity, selection and caret predictability, inline syntax fidelity, and Source/WYSIWYG continuity.</li>
<li>Strengthened operation-based Undo grouping, structured-block keyboard editing, and table editing correctness.</li>
<li>Added Focus and Typewriter writing-view stability.</li>
</ul>
<p>See the <a href="https://github.com/Bulls1986/Inkiva/releases/tag/v0.5.0" class="link">v0.5.0 release</a>.</p>

<p>Published 2026-09-24.</p>
<ul>
<li>Improved large-document activation and renderer/editor performance.</li>
<li>Strengthened editor runtime boundaries, typed IPC contracts, event-bus ownership, virtual-surface behavior and background scheduler lifecycle.</li>
<li>Improved command focus readiness, async geometry stability, benchmark trustworthiness and lifecycle/memory ownership.</li>
<li>Added architecture and correctness governance to make future changes more predictable.</li>
</ul>
<p>See the <a href="https://github.com/Bulls1986/Inkiva/releases/tag/v0.4.1" class="link">v0.4.1 release</a>.</p>

<p>Published 2026-09-21.</p>
<ul>
<li>Refined the desktop titlebar, editor layout and document status presentation.</li>
<li>Improved manual-save/autosave ordering and unsaved-close protection.</li>
<li>Added top-level block virtualization and improved virtualized scrolling with asynchronous diagrams.</li>
<li>Improved settings persistence and website metadata/canonical URLs.</li>

<h2 id="v030">v0.3.0<a class="anchor" aria-hidden tabindex="-1" href="#v030">#</a></h2>
<p>Inkiva's document-first release. The editor keeps standard Markdown files and folders at the center of the workflow.</p>
<p><strong>Features</strong></p>
<ul>
<li>Recent documents and folders on the welcome surface, with pin, remove, clear, and reveal actions.</li>
<li>Quick Open, document tabs, optional two-pane comparison, outline navigation, and folder-wide Markdown search.</li>
<li>Standard Markdown links, backlinks, image paths, tables, diagrams, and code blocks remain portable.</li>
<li>Local history, autosave/recovery protection, updater validation, and release artifact checks are part of the quality gate.</li>
<li>Official desktop packages are published for Windows x64 and macOS Intel/Apple Silicon.</li>
</ul>
<p><strong>Compatibility</strong></p>
<ul>
<li>Existing CommonMark/GFM documents remain plain Markdown; Inkiva does not add Wiki Links, hidden markers, or a workspace database.</li>
<li>macOS packages are currently unsigned/not notarized; Gatekeeper may require an explicit first launch approval.</li>
</ul>
