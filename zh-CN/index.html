不止是一款 Markdown 编辑器

文件之外的能力，始终保持轻量。

Inkiva 围绕普通 Markdown 文件提供导航、关联与恢复能力，但不会把文件夹变成另一种私有格式。

01

写得漂亮

标题、强调、链接、列表和代码会在原处渲染，让你始终保持写作状态。你看到的，就是正在写的内容。

As you type
Bold, italics, links and code all render instantly.
02

自然导航

打开文件和文件夹，把最近文档留在手边。需要的内容，几次点击就能找到。

文档▾写作Ideas.md恰到好处.mdRoadmap.md
最近文档恰到好处.mdIdeas.mdRoadmap.mdMeeting Notes.md
03

找回你的工作

快速打开最近文档，或搜索文件夹中的 Markdown 文件，不必离开编辑器就能回到刚才的工作。

恰到好处×
恰到好处.md~/Documents/Writing/恰到好处.md
Project Plan.md~/Documents/Work/Project Plan.md
Meeting Notes.md~/Documents/Work/Meeting Notes.md
04

让文档保持连接

使用标准的相对 Markdown 链接和标题。反向链接与修复提示，帮助你维护文档之间的关系。

See also: [Roadmap](../Roadmap.md)

and [Ideas](Ideas.md).

05

放心写作

文件始终保存在自己的设备上。本地历史、自动保存和崩溃恢复，会在写作时保护你的内容。

本地历史浏览并恢复文档的历史版本。
