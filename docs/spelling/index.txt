<h2 id="features">Features<a class="anchor" aria-hidden tabindex="-1" href="#features">#</a></h2>
<p><strong>Automatic language detection:</strong></p>
<p>Inkiva can try to automatically detect the language while typing and we're currently support over 160 languages by Compact Language Detector.</p>
<p><strong>Don't underline misspelled words:</strong></p>
<p>If you don't like that all spelling mistakes are red highlighted, you can disable this feature in settings but still benefit from manually spell checking via right-click menu. Disabling constantly spell checking will also improve performance overall.</p>
<p><strong>Adding words to dictionary:</strong></p>
<p>You can add words to the selected dictionary by right-clicking on a misspelled word and select <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Add to Dictionary</span></span></code></span> or remove a previously added word. If you want to temporary ignore a word, select <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Ignore</span></span></code></span>.</p>
<h2 id="manage-dictionaries">Manage dictionaries<a class="anchor" aria-hidden tabindex="-1" href="#manage-dictionaries">#</a></h2>
<h3 id="macos-spell-checker">macOS spell checker<a class="anchor" aria-hidden tabindex="-1" href="#macos-spell-checker">#</a></h3>
<p>You need to add the additional language dictionaries via <em>"Language &#x26; Region"</em> in your system preferences pane.</p>
<h3 id="windows-spell-checker">Windows spell checker<a class="anchor" aria-hidden tabindex="-1" href="#windows-spell-checker">#</a></h3>
<p>On Windows 10, you need to add additional language dictionaries via <em>"Language"</em> in your <em>"Time &#x26; language"</em> settings. Add the additional language(s) and download the <em>"Basic typing"</em> language option for each language.</p>
<h3 id="hunspell">Hunspell<a class="anchor" aria-hidden tabindex="-1" href="#hunspell">#</a></h3>
<p>Please go to spelling settings and scroll to the bottom. Now you see a list of available language dictionaries and can add additional dictionaries via the drop-down menu at the bottom. Please note that an active internet connection is required to download a dictionary!</p>
