<h2 id="breaks">Breaks<a class="anchor" aria-hidden tabindex="-1" href="#breaks">#</a></h2>
<p>You can use multiple consecutive newline characters (<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>\n</span></span></code></span>) to create extra spacing between sections in a markdown document. However, if you need to ensure that extra newlines are not collapsed, you can use as many HTML <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>&#x3C;br></span></span></code></span> elements as you want.</p>
<p>Alternatively you can add <strong>two spaces</strong> spaces at the end of your paragraph to force a soft linebreak.</p>

<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>***</span></span></code></span>: three consecutive asterisks</li>

<h2 id="links">Links<a class="anchor" aria-hidden tabindex="-1" href="#links">#</a></h2>
<h3 id="autolinks">Autolinks<a class="anchor" aria-hidden tabindex="-1" href="#autolinks">#</a></h3>
<p>Autolinks are absolute URIs and email addresses inside <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>&#x3C;</span></span></code></span> and <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>></span></span></code></span>. They are parsed as links, where the URI or email address itself is used as the link's label.</p>
<figure data-rehype-pretty-code-figure=""><div class="code"><div class="code-bar"><span class="lang">markdown</span><button class="copy-btn" type="button" data-copy="<http://foo.bar.baz>" aria-label="Copy code"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><rect x="9" y="9" width="13" height="13" rx="2" ry="2"></rect><path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"></path></svg><span class="label">Copy</span></button></div><pre tabindex="0" data-language="markdown" data-theme="github-dark-dimmed github-light"><code data-language="markdown" data-theme="github-dark-dimmed github-light" style="display: grid;"><span data-line=""><span style="--shiki-dark:#ADBAC7;--shiki-light:#24292E">&#x3C;</span><span style="--shiki-dark:#ADBAC7;--shiki-dark-text-decoration:underline;--shiki-light:#24292E;--shiki-light-text-decoration:underline">http://foo.bar.baz</span><span style="--shiki-dark:#ADBAC7;--shiki-light:#24292E">></span></span></code></pre></div></figure>
<p>Renders to:</p>
<p><a href="http://foo.bar.baz" class="link">http://foo.bar.baz</a></p>
<p>URIs or email addresses that are not wrapped in angle brackets are not recognized as valid autolinks by markdown parsers.</p>

<h3 id="unordered">Unordered<a class="anchor" aria-hidden tabindex="-1" href="#unordered">#</a></h3>

<h2 id="diagrams">Diagrams<a class="anchor" aria-hidden tabindex="-1" href="#diagrams">#</a></h2>
<p>Inkiva support class, flow chart, gantt and sequence diagrams powered by flowchart.js, mermaid and Vega-Lite. <a href="#code" class="link">Code</a> blocks with special language identifiers are used for diagrams.</p>
<p>For example, this:</p>
<pre>## Vega-lite diagram

Please see [introduction to Vega-Lite](https://vega.github.io/vega-lite/tutorials/getting_started.html) for details.

```vega-lite
{
  "data": {
    "values": [
      {"a": "C", "b": 2}, {"a": "C", "b": 7}, {"a": "C", "b": 4},
      {"a": "D", "b": 1}, {"a": "D", "b": 2}, {"a": "D", "b": 6},
      {"a": "E", "b": 8}, {"a": "E", "b": 4}, {"a": "E", "b": 7}
    ]
  },
  "mark": "point",
  "encoding": {
    "x": {"field": "a", "type": "nominal"},
    "y": {"field": "b", "type": "quantitative"}
  }
}
```

## Flowchart

```flowchart
st=>start: Start|past
e=>end: End|future
op1=>operation: My Operation|past
op2=>operation: Stuff|current
sub1=>subroutine: My Subroutine|invalid
cond=>condition: Yes
or No?|approved:>http://www.google.com
c2=>condition: Good idea|rejected
io=>inputoutput: catch something...|future

st->op1(right)->cond
cond(yes, right)->c2
cond(no)->sub1(left)->op1
c2(yes)->io->e
c2(no)->op2->e
```

## Sequence diagram

```sequence
Title: Here is a title
A->B: Normal line
B-->C: Dashed line
C->>D: Open arrow
D-->>A: Dashed open arrow
```

## Flowchart

```mermaid
graph TD;
    A-->B;
    A-->C;
    B-->D;
    C-->D;
```

## Sequence diagram

```mermaid
sequenceDiagram
    participant Alice
    participant Bob
    Alice->>John: Hello John, how are you?
    loop Healthcheck
        John->>John: Fight against hypochondria
    end
    Note right of John: Some note
    John-->>Alice: Great!
    John->>Bob: How about you?
    Bob-->>John: Jolly good!
```

## Gantt diagram

```mermaid
gantt
dateFormat  YYYY-MM-DD
title Adding GANTT diagram to mermaid
excludes weekdays 2014-01-10

section A section
Completed task            :done,    des1, 2014-01-06,2014-01-08
Active task               :active,  des2, 2014-01-09, 3d
Future task               :         des3, after des2, 5d
Future task2               :         des4, after des3, 5d
```

<h2 id="raw-html">Raw HTML<a class="anchor" aria-hidden tabindex="-1" href="#raw-html">#</a></h2>
<p>Any text between <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>&#x3C;</span></span></code></span> and <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>></span></span></code></span> that looks like an HTML tag will be parsed as a raw HTML tag and rendered to HTML without escaping.</p>
<p>Example:</p>
<figure data-rehype-pretty-code-figure=""><div class="code"><div class="code-bar"><span class="lang">markdown</span><button class="copy-btn" type="button" data-copy="**Visit <a href=&#x22;https://github.com&#x22;>Jon Schlinkert&#x27;s GitHub Profile</a>.**" aria-label="Copy code"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><rect x="9" y="9" width="13" height="13" rx="2" ry="2"></rect><path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"></path></svg><span class="label">Copy</span></button></div><pre tabindex="0" data-language="markdown" data-theme="github-dark-dimmed github-light"><code data-language="markdown" data-theme="github-dark-dimmed github-light" style="display: grid;"><span data-line=""><span style="--shiki-dark:#ADBAC7;--shiki-dark-font-weight:bold;--shiki-light:#24292E;--shiki-light-font-weight:bold">**Visit &#x3C;a href="https://github.com">Jon Schlinkert's GitHub Profile&#x3C;/a>.**</span></span></code></pre></div></figure>
<p>Renders to:</p>
<p><strong>Visit <a href="https://github.com" class="link">Jon Schlinkert's GitHub Profile</a>.</strong></p>
<h2 id="escaping-with-backslashes">Escaping with backslashes<a class="anchor" aria-hidden tabindex="-1" href="#escaping-with-backslashes">#</a></h2>

<p>Renders to:</p>
<p>*this is not italic*</p>
