<p>A Fast Gate is a bounded PR signal, not a substitute for the formal release qualification matrix. Preserve fixture identity, environment details, raw measurements and the gate verdict when recording evidence.</p>

<h2 id="measurement-discipline">Measurement discipline<a class="anchor" aria-hidden tabindex="-1" href="#measurement-discipline">#</a></h2>
<ul>
<li>Use the same fixture, build mode and interaction sequence when comparing commits.</li>
<li>Record OS, CPU, memory, display scale, Node/Electron versions and whether the run is cold or warm.</li>
<li>Separate main-process, renderer and filesystem costs; do not infer one from another.</li>
<li>Report p50/p95/p99 and sample count where the gate defines them; retain raw output.</li>
<li>Do not relax a threshold or substitute a smoke run for a formal gate without the required architecture/release approval.</li>
</ul>
