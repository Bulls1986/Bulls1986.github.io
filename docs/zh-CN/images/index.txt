<h2 id="插入图片">插入图片<a class="anchor" aria-hidden tabindex="-1" href="#插入图片">#</a></h2>
<p>可粘贴图片、拖放到编辑器、输入 Markdown 图片语法或调用图片命令。通过 <strong>Preferences → Image</strong> 选择：</p>
<ul>
<li><strong>复制到本地目录</strong>：创建新的资源文件，再插入相对于当前文档的路径。</li>
<li><strong>保留原路径</strong>：只引用原文件；绝对路径在其他电脑上通常不可移植。</li>
<li><strong>PicGo 上传</strong>：需要先配置外部 PicGo 工具，具体见<a href="/docs/zh-CN/image-uploader/" class="link">图片上传配置</a>。</li>
</ul>
<h2 id="相对目录">相对目录<a class="anchor" aria-hidden tabindex="-1" href="#相对目录">#</a></h2>
<p><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>assets</span></span></code></span> 表示当前文档旁的资源目录，<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>../assets</span></span></code></span> 表示上一级目录，<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>.</span></span></code></span> 表示当前目录，<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>assets_${filename}</span></span></code></span> 会根据文档文件名生成目录名。</p>
<p>图片的相对路径基于<strong>已保存的 Markdown 文件所在目录</strong>计算，不会偷偷基于应用程序工作目录。未保存的新文档如果没有可靠路径锚点，需要先保存文档或选择其他明确的插入方式。</p>
<p>导入使用防覆盖策略，同名反复粘贴不应覆盖已存在资源；只有实际文件写入成功后才应生成对应 Markdown 引用。</p>
<h2 id="替换缩放和缺图处理">替换、缩放和缺图处理<a class="anchor" aria-hidden tabindex="-1" href="#替换缩放和缺图处理">#</a></h2>
<p>选择可视编辑器中的图片，使用已有控件修改替代文字/标题、拖动缩放控制条或通过 <strong>Choose Image</strong> 更换源文件。图片加载失败时，可点击失败图片，切换到 <strong>Embed Image</strong> 输入框填写新的本地相对路径并确认。</p>
<p><img src="/docs/assets/inkiva-image-failure.png" alt="Windows v0.6.0 图片加载失败及 Embed Image 重连入口"></p>
<p><img src="/docs/assets/inkiva-image-relinked.png" alt="重新指向有效本地图片后的实机截图"></p>
<p>实测将 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>./missing.png</span></span></code></span> 改为 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>./correct.png</span></span></code></span> 后，图片状态变为加载成功，且 Markdown 保存了新路径。</p>
<p>导入失败应保留原始 Markdown，避免留下永久 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>loading-*</span></span></code></span> 占位符；在进行中的替换操作不应覆盖后续用户的编辑。</p>
