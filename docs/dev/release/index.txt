<p>The flow below covers both release candidates and stable releases — same steps, only the version string differs.</p>

<ul>
<li>Push access to <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>inkiva/inkiva</span></span></code></span></li>

</ul>
