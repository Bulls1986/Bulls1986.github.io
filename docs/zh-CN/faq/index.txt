<h2 id="支持哪些平台">支持哪些平台？<a class="anchor" aria-hidden tabindex="-1" href="#支持哪些平台">#</a></h2>
<p>Windows 10/11 x64，以及 macOS 11 或更新版本（Intel、Apple Silicon）。Linux 不属于当前正式发布目标。</p>
<h2 id="是否免费开源">是否免费开源？<a class="anchor" aria-hidden tabindex="-1" href="#是否免费开源">#</a></h2>
<p>是。Inkiva 采用 <a href="https://github.com/Bulls1986/Inkiva/blob/develop/LICENSE" class="link">GPL-3.0-or-later</a>，源代码位于 <a href="https://github.com/Bulls1986/Inkiva" class="link">GitHub</a>。</p>
<h2 id="是知识库软件还是-markdown-编辑器">是知识库软件还是 Markdown 编辑器？<a class="anchor" aria-hidden tabindex="-1" href="#是知识库软件还是-markdown-编辑器">#</a></h2>
<p>它优先是<strong>文档编辑器</strong>。它能够识别文件夹、普通 Markdown 链接、标题和反向链接，但不会要求你迁移进专有工作区数据库。</p>
<h2 id="如何创建打开和修复本地文档链接">如何创建、打开和修复本地文档链接？<a class="anchor" aria-hidden tabindex="-1" href="#如何创建打开和修复本地文档链接">#</a></h2>
<p>打开文件夹后，使用 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Ctrl+K</span></span></code></span>（Windows）或 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Command+K</span></span></code></span>（macOS）插入链接。点击链接时需要修饰键才能跟随，普通点击是编辑操作。在 <strong>More → Document Info</strong> 中查看 Backlinks 或断链；先 <strong>Locate</strong> 后 <strong>Repair</strong>，取消修复时不改写源文件。</p>
<h2 id="图片显示不出来怎么办">图片显示不出来怎么办？<a class="anchor" aria-hidden tabindex="-1" href="#图片显示不出来怎么办">#</a></h2>
<p>检查 Markdown 图片相对路径及资源是否随文档一起复制。使用现有图片编辑控件 <strong>Choose Image</strong> 重新选择图片；详见<a href="/docs/zh-CN/images/" class="link">图片处理</a>。</p>
<h2 id="自动保存是不是云备份">自动保存是不是云备份？<a class="anchor" aria-hidden tabindex="-1" href="#自动保存是不是云备份">#</a></h2>
<p>不是。自动保存、Local History 和崩溃恢复都不能替代独立备份或跨设备同步。</p>
