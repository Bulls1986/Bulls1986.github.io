<h3 id="prerequisites">Prerequisites<a class="anchor" aria-hidden tabindex="-1" href="#prerequisites">#</a></h3>
<p>Before you can get started developing, you need set up your build environment:</p>
<ul>
<li>Node.js <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>>=20.19.0</span></span></code></span> and pnpm <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>>=10</span></span></code></span></li>
<li>Python <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>>=3.12</span></span></code></span> for node-gyp</li>
<li>C++ compiler and development tools</li>
<li>Build is supported on Linux, macOS and Windows</li>
</ul>
<p><strong>Additional development dependencies on Linux:</strong></p>
<ul>
<li>libX11 (with headers)</li>
<li>libxkbfile (with headers)</li>
<li>libsecret (with headers)</li>
<li>libfontconfig (with headers)</li>
<li>rpm (if building on Debian)</li>
</ul>
<p>On Debian-based Linux: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>sudo apt-get install libx11-dev libxkbfile-dev libsecret-1-dev libfontconfig-dev rpm</span></span></code></span></p>
<p>On Red Hat-based Linux: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>sudo dnf install libX11-devel libxkbfile-devel libsecret-devel fontconfig-devel</span></span></code></span></p>
<p>On Arch Linux: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>sudo pacman -S libx11 libxkbfile libsecret fontconfig</span></span></code></span></p>
<p><strong>Additional development dependencies on Windows:</strong></p>
<ul>
<li>Windows 10 SDK (only needed before Windows 10)</li>
<li>Visual Studio 2022 (Build Tools for Visual Studio 2022). You also need the spectre-mitigated MSVC libs — see <a href="/docs/dev/overview#13-windows-specific-pre-requisites" class="link">developer README §1.3</a> for the exact components to install.</li>
</ul>
<h3 id="lets-build">Let's build<a class="anchor" aria-hidden tabindex="-1" href="#lets-build">#</a></h3>
<ol>
<li>Go to <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>inkiva</span></span></code></span> folder</li>
<li>Install dependencies: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>pnpm install</span></span></code></span></li>
<li>Build Inkiva binaries and packages: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>pnpm run build</span></span></code></span></li>
<li>Inkiva binary is located under <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>dist</span></span></code></span> folder (electron-builder output)</li>
</ol>
<p>Copy the build app to applications folder, or if on Windows run the executable installer.</p>
