<h2 id="text-selection-and-formatting">Text selection and formatting<a class="anchor" aria-hidden tabindex="-1" href="#text-selection-and-formatting">#</a></h2>
<p>Select text with the mouse, double-click a word, or use <kbd>Shift</kbd>+<kbd>Arrow Keys</kbd>. Use the <strong>Format</strong> menu or the available keyboard shortcuts to apply bold, italic, underline, strikethrough, inline code, inline math, links, images, and clear formatting. The command launcher provides a searchable route to the same actions.</p>
<p>Inkiva updates the rendered result as you edit. The active appearance controls the writing surface and syntax colors; editor font, size, line height, and width are configured in <strong>Preferences → Editor</strong>.</p>
<h2 id="quick-insert-and-block-actions">Quick insert and block actions<a class="anchor" aria-hidden tabindex="-1" href="#quick-insert-and-block-actions">#</a></h2>
<p>In an empty paragraph, type <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>/</span></span></code></span> to open the quick-insert menu. Search by continuing to type, navigate with the arrow keys, and press <kbd>Enter</kbd> to insert the selected block. The menu can create headings, paragraphs, lists, task lists, quotes, tables, code blocks, front matter, thematic breaks, and supported diagram blocks.</p>
<p>For commands that are not visible in the editor, open the titlebar command launcher:</p>
<p><img src="/docs/assets/inkiva-command-palette.png" alt="Inkiva command launcher for searching documents, headings, and commands"></p>
<p>The paragraph menu also exposes actions such as <strong>Turn Into</strong>, duplicate, create paragraph, and delete paragraph. These actions operate on the current block or selection.</p>
<h2 id="markdown-formatting">Markdown formatting<a class="anchor" aria-hidden tabindex="-1" href="#markdown-formatting">#</a></h2>
<p>Inkiva follows CommonMark and GitHub Flavored Markdown behavior for the supported syntax. List markers, heading style, indentation, front matter, HTML, footnotes, and other extensions can be configured in <a href="/docs/preferences/" class="link">Preferences</a>. See <a href="/docs/markdown-syntax/" class="link">Markdown syntax</a> for the rendered feature reference.</p>
<h2 id="autocompletion">Autocompletion<a class="anchor" aria-hidden tabindex="-1" href="#autocompletion">#</a></h2>
<p>The editor can close brackets, quotes, and Markdown delimiters as you type. These behaviors are enabled by default and can be configured independently with <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>autoPairBracket</span></span></code></span>, <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>autoPairMarkdownSyntax</span></span></code></span>, and <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>autoPairQuote</span></span></code></span>.</p>
<h2 id="tables">Tables<a class="anchor" aria-hidden tabindex="-1" href="#tables">#</a></h2>
<p>Use the quick-insert menu or <strong>Paragraph → Table</strong> to create a table. The table controls let you add or remove rows and columns, resize the table, move rows or columns, and align cell content. Inline formatting remains available inside table cells.</p>
<h2 id="images">Images<a class="anchor" aria-hidden tabindex="-1" href="#images">#</a></h2>
<p>Type <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>![]()</span></span></code></span> or use the image command to insert an image. Inkiva can select a local file, accept a pasted path or URL, copy an image into a relative directory, or send it to the configured <a href="/docs/image-uploader/" class="link">PicGo uploader</a>. Image behavior is controlled in <strong>Preferences → Image</strong>; see <a href="/docs/images/" class="link">Image support</a> for path and folder examples.</p>
<h2 id="links-and-emoji">Links and emoji<a class="anchor" aria-hidden tabindex="-1" href="#links-and-emoji">#</a></h2>
<p>Click a link in the preview to inspect or edit its Markdown target. The inline tools also provide an emoji picker and link actions when the relevant command is available from the editor context menu.</p>
<h2 id="focus-and-typewriter-modes">Focus and typewriter modes<a class="anchor" aria-hidden tabindex="-1" href="#focus-and-typewriter-modes">#</a></h2>
<p>Focus mode fades surrounding paragraphs so the current line remains prominent. Typewriter mode keeps the active line near the center of the editor. In the default Typora shortcut style, use <kbd>F8</kbd> for focus mode and <kbd>F9</kbd> for typewriter mode. Their commands are also available under <strong>View</strong> and in the command launcher.</p>
<h2 id="file-encoding-and-line-endings">File encoding and line endings<a class="anchor" aria-hidden tabindex="-1" href="#file-encoding-and-line-endings">#</a></h2>
<p>Inkiva can guess a file's encoding when it opens. UTF-8 is the packaged default; the default encoding and automatic detection can be changed in <strong>Preferences → Editor</strong>. The current encoding and line-ending commands are available through the command launcher.</p>
<h2 id="find-and-replace">Find and replace<a class="anchor" aria-hidden tabindex="-1" href="#find-and-replace">#</a></h2>
<p><strong>Inside the document:</strong> press <kbd>CmdOrCtrl</kbd>+<kbd>F</kbd> to search the current document and use the replace controls when needed.</p>
<p><strong>Across the opened folder:</strong> open the <strong>Search</strong> sidebar panel to search Markdown files in the current folder.
