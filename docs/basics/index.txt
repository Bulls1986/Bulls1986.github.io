<h2 id="getting-started">Getting started<a class="anchor" aria-hidden tabindex="-1" href="#getting-started">#</a></h2>
<p>Inkiva is a realtime preview editor for markdown with various markdown extensions. You can simply write and edit text and Inkiva hides all unnecessary syntax elements. When you first start Inkiva an empty editor window is shown. You can see <a href="/docs/key-bindings" class="link">key bindings</a> or command palette (<kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) for all available commands or just type <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>@</span></span></code></span> to get an overlay with available text elements. Inkiva provides a minimal and simple interface and in the next sections you can learn more about the interface and features.</p>
<p><img src="/docs/assets/inkiva-default.png" alt=""></p>
<h3 id="interface">Interface<a class="anchor" aria-hidden tabindex="-1" href="#interface">#</a></h3>
<h4 id="toggle-sidebar">Toggle sidebar<a class="anchor" aria-hidden tabindex="-1" href="#toggle-sidebar">#</a></h4>
<p>The sidebar consists of four panels and you can toggle the sidebar by pressing <kbd>CmdOrCtrl</kbd>+<kbd>J</kbd>:</p>
<ul>
<li>Filesystem explorer (tree view) of the opened root directory. The tree also exposes a collapsible <em>Opened Files</em> subsection — toggle it via the <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>openedFilesInSidebar</span></span></code></span> preference.</li>
<li>Find in files</li>
<li>Table of contents of the selected tab</li>
<li>Document Info: backlinks and Local History for the selected document</li>
</ul>
<h4 id="toggle-tabs">Toggle tabs<a class="anchor" aria-hidden tabindex="-1" href="#toggle-tabs">#</a></h4>
<p>Inkiva can be used as a single editor but opens all files in a separate tab. Tabs can be toggled via <kbd>CmdOrCtrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd>, reordered by drag and drop, pinned, and reopened after closing.</p>
<p><strong>Want to use tabs without showing them?</strong></p>
<p>You can hide tabs and use key bindings such as <kbd>CmdOrCtrl</kbd>+<kbd>Tab</kbd> to cycle through tabs or the sidebar <em>opened files</em> panel.</p>
<h4 id="split-editor">Split Editor<a class="anchor" aria-hidden tabindex="-1" href="#split-editor">#</a></h4>
<p>Use <strong>View → Split Editor</strong> or <kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>\</kbd> to open a second document pane. Inkiva shows A|B when another tab is available and A|A when the current document is the only open tab. The secondary pane is a comparison surface; choose <strong>Use as editor</strong> when you want to continue editing that document.</p>
<h4 id="recent-documents-and-quick-open">Recent documents and Quick Open<a class="anchor" aria-hidden tabindex="-1" href="#recent-documents-and-quick-open">#</a></h4>
<p>The welcome surface lists recently opened documents and folders. <strong>Quick Open</strong> (<kbd>CmdOrCtrl</kbd>+<kbd>P</kbd>) searches Markdown files in the current folder and gives already-open documents priority.</p>
<p><img src="/docs/assets/inkiva-interface-1.png" alt=""></p>
<h4 id="switch-between-editor-modes">Switch between editor modes<a class="anchor" aria-hidden tabindex="-1" href="#switch-between-editor-modes">#</a></h4>
<p>You can use <kbd>CmdOrCtrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd> to switch between the preview and source-code editor. The realtime preview editor is the default editor with many features. A detailed overview of all features can be found <a href="/docs/editing" class="link">here</a>.</p>
<h4 id="typewriter-and-focus-mode">Typewriter and focus mode<a class="anchor" aria-hidden tabindex="-1" href="#typewriter-and-focus-mode">#</a></h4>
<p>Use <kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> to enter distraction free focus mode or <kbd>CmdOrCtrl</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd> for typewriter.</p>

<h2 id="open-and-modify-markdown-files">Open and modify markdown files<a class="anchor" aria-hidden tabindex="-1" href="#open-and-modify-markdown-files">#</a></h2>
<h3 id="open-your-first-file">Open your first file<a class="anchor" aria-hidden tabindex="-1" href="#open-your-first-file">#</a></h3>
<p>You can use the menu <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>File -> Open File</span></span></code></span> or press <kbd>CmdOrCtrl</kbd>+<kbd>O</kbd> to open a file dialog to choose a markdown file. Another way to is to launch Inkiva with directories or files via command line.</p>
<h3 id="save-your-edited-file">Save your edited file<a class="anchor" aria-hidden tabindex="-1" href="#save-your-edited-file">#</a></h3>
<p>After some modifications you can save your file via <kbd>CmdOrCtrl</kbd>+<kbd>S</kbd> or use <em>save as</em> to use a different file name.</p>
<h3 id="open-a-directory">Open a directory<a class="anchor" aria-hidden tabindex="-1" href="#open-a-directory">#</a></h3>
<p>Inkiva also has support to open a directory via <kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> or the sidebar button <em>Open Folder</em>. After opening a directory all files and directories are shown in the sidebar tree view. The tree view allows you to open further files, browse and modify files or directories inside the opened root directory. Above the tree view are all opened files located. You can also use quick open (<kbd>CmdOrCtrl</kbd>+<kbd>P</kbd>) to quickly open a file from the opened root directory or editor and navigate via arrow keys or select a file via mouse. To view another sidebar panel like find in files click on the left sidebar icons.</p>
<p><img src="/docs/assets/inkiva-interface-2.png" alt=""></p>
<h2 id="appearances">Appearances<a class="anchor" aria-hidden tabindex="-1" href="#appearances">#</a></h2>
<p>You can change the application appearance by selecting Inkiva Light, Inkiva Dark, or Inkiva Paper from the <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Theme</span></span></code></span> menu. Inkiva Light and Inkiva Dark can also follow the system appearance.</p>
<h2 id="preferences">Preferences<a class="anchor" aria-hidden tabindex="-1" href="#preferences">#</a></h2>
<p>You can control and modify all preferences in the settings window or edit <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>preferences.json</span></span></code></span> in the <a href="/docs/application-data-directory" class="link">application data directory</a>. Detailed information about the preference file can be found <a href="/docs/preferences" class="link">here</a>.</p>
