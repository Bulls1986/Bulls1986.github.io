<h2 id="main-interface">Main interface<a class="anchor" aria-hidden tabindex="-1" href="#main-interface">#</a></h2>
<p><img src="/docs/assets/inkiva-interface.png" alt=""></p>
<ul>
<li>Green: titlebar</li>
<li>Orange: sidebar</li>
<li>Red: editor with tabs and per-tab notification at the bottom</li>
</ul>
<h3 id="titlebar">Titlebar<a class="anchor" aria-hidden tabindex="-1" href="#titlebar">#</a></h3>
<p>The titlebar is located at the top of the window and shows the current opened file path and the menu on Linux and Windows. On macOS we're using client-side decorations (CSD) that look similar to the picture above. On Linux and Windows there are two type of titlebar: a custom CSD that you can see in the image above and the native one.</p>
<h3 id="sidebar">Sidebar<a class="anchor" aria-hidden tabindex="-1" href="#sidebar">#</a></h3>
<p>The sidebar is an optional feature of Inkiva that contains three panels and has a variable width. The first panel is a tree view of the opened root directory; it also hosts a collapsible <em>Opened Files</em> subsection (toggle via the <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>openedFilesInSidebar</span></span></code></span> preference). The latter two panels are a folder searcher (find in files) that is powered by ripgrep and a table of contents of the currently opened document.</p>
<h3 id="editor">Editor<a class="anchor" aria-hidden tabindex="-1" href="#editor">#</a></h3>
<p>The editor is the core element that hosts the realtime preview editor called Muya and consists of three parts. Tabs are located at the top and at the bottom the per-tab notification bar is located for events like file changed or deleted. The main part is the editor that is either provided by Muya or CodeMirror for the source-code editor. There are multiple overlays available like inline toolbar, emoji picker, quick insert or image
