<h2 id="appimage">AppImage<a class="anchor" aria-hidden tabindex="-1" href="#appimage">#</a></h2>
<p><a href="https://github.com/Bulls1986/Inkiva/releases/latest" class="link">Download the AppImage</a> and type the following:</p>
<ol>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>chmod +x inkiva-%version%-x86_64.AppImage</span></span></code></span></li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>./inkiva-%version%-x86_64.AppImage</span></span></code></span></li>
<li>Now you can execute Inkiva.</li>
</ol>
<h3 id="installation">Installation<a class="anchor" aria-hidden tabindex="-1" href="#installation">#</a></h3>
<p>You cannot really install an AppImage. It's a file which can run directly after getting executable permission. To integrate it into desktop environment, you can either create desktop entry manually <strong>or</strong> use <a href="https://github.com/TheAssassin/AppImageLauncher" class="link">AppImageLauncher</a>.</p>
<h4 id="desktop-file-creation">Desktop file creation<a class="anchor" aria-hidden tabindex="-1" href="#desktop-file-creation">#</a></h4>

<h4 id="appimagelauncher-integration">AppImageLauncher integration<a class="anchor" aria-hidden tabindex="-1" href="#appimagelauncher-integration">#</a></h4>
<p>You can integrate the AppImage into the system via <a href="https://github.com/TheAssassin/AppImageLauncher" class="link">AppImageLauncher</a>. It will handle the desktop entry automatically.</p>
<h3 id="uninstallation">Uninstallation<a class="anchor" aria-hidden tabindex="-1" href="#uninstallation">#</a></h3>
<ol>
<li>Delete AppImage file.</li>
<li>Delete your desktop file if exists.</li>
<li>Delete your user settings: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>~/.config/inkiva</span></span></code></span></li>
</ol>
<h3 id="custom-launch-script">Custom launch script<a class="anchor" aria-hidden tabindex="-1" href="#custom-launch-script">#</a></h3>

<li>

</li>
<li>
<p><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>chmod +x ~/bin/inkiva.AppImage</span></span></code></span></p>
</li>
