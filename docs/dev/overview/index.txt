<h2 id="workspace-map">Workspace map<a class="anchor" aria-hidden tabindex="-1" href="#workspace-map">#</a></h2>
<ul>
<li><strong>packages/desktop/</strong> — Electron desktop application: main process, sandboxed preload, Vue 3 renderer, shared process contracts and desktop tests.</li>
<li><strong>packages/muya/</strong> — active TypeScript Markdown/editor engine published inside the workspace as <strong>@muyajs/core</strong>.</li>
<li><strong>packages/muyajs/</strong> — legacy MarkText-era JavaScript package retained for compatibility/reference; it is not the desktop application's active editor-engine dependency.</li>
<li><strong>packages/website/</strong> — Next.js product website and the source for the public user/developer documentation.</li>
</ul>
<p>The active desktop editor uses the TypeScript Muya package. Do not use the old single-package src/main, src/renderer or src/muya layout as a description of the repository root.</p>
<h2 id="prerequisites">Prerequisites<a class="anchor" aria-hidden tabindex="-1" href="#prerequisites">#</a></h2>
<ul>
<li>Node.js <strong>20.19.0 or later</strong>.</li>
<li>pnpm <strong>10.x</strong>. The root package manifest pins <strong>10.33.4</strong> through its packageManager field.</li>
<li>Python <strong>3.12 or later</strong> for native modules.</li>
<li>Windows: Visual Studio 2022 Build Tools with the required MSVC C++ components.</li>
<li>macOS: Xcode Command Line Tools.</li>
</ul>
<p>The known-good local Windows baseline recorded by the repository is Node.js 24.21.0, pnpm 10.33.4 and Python 3.12.x. CI pins its own versions: the default setup action uses Node 22.21.1, while the release workflow currently overrides it to Node 24.14.1. Check the workflow files before changing these pins.</p>
