<h3 id="what-are-the-supported-platforms">What are the supported platforms?<a class="anchor" aria-hidden tabindex="-1" href="#what-are-the-supported-platforms">#</a></h3>
<p>Inkiva publishes desktop builds for:</p>
<ul>
<li>Windows 10 or 11, x64</li>
<li>macOS 11 (Big Sur) or later, Intel and arm64 (Apple Silicon)</li>
</ul>
<p>The editor runs on standard Markdown files and does not require an account, cloud service, or project database.</p>
<h3 id="is-inkiva-open-source-and-free">Is Inkiva open-source and free?<a class="anchor" aria-hidden tabindex="-1" href="#is-inkiva-open-source-and-free">#</a></h3>
<p>Yes. Inkiva is licensed under the <a href="https://github.com/Bulls1986/Inkiva/blob/develop/LICENSE" class="link">GPL-3.0-or-later</a> license and is free to use. The source code is available on <a href="https://github.com/Bulls1986/Inkiva" class="link">GitHub</a>.</p>
<h3 id="is-inkiva-a-knowledge-management-app">Is Inkiva a knowledge-management app?<a class="anchor" aria-hidden tabindex="-1" href="#is-inkiva-a-knowledge-management-app">#</a></h3>
<p>Inkiva is a document-first Markdown editor. It understands folders, files, headings, standard links, and local history; it intentionally does not turn your documents into a separate workspace database or require proprietary Markdown syntax.</p>
<h3 id="where-can-i-find-documentation">Where can I find documentation?<a class="anchor" aria-hidden tabindex="-1" href="#where-can-i-find-documentation">#</a></h3>
<p>The full documentation is available on the Inkiva website:</p>
<ul>
<li><a href="/docs/introduction/" class="link">End-user documentation</a></li>
<li><a href="/docs/dev/overview/" class="link">Developer documentation</a></li>
</ul>
<h3 id="can-i-run-a-portable-version-of-inkiva">Can I run a portable version of Inkiva?<a class="anchor" aria-hidden tabindex="-1" href="#can-i-run-a-portable-version-of-inkiva">#</a></h3>
<p>Yes. See <a href="/docs/portable/" class="link">Portable mode</a> for details about keeping configuration beside the application.</p>
