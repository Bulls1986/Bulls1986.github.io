Markdown 编辑器对比

Inkiva、Typora 与 MarkText 如何选择？

面向希望直接编辑渲染后文档、同时保留普通 Markdown 文件的用户，对三款桌面 Markdown 编辑器进行事实对比。

信息依据 2026 年 10 月 30 日可查的官方产品页面和代码仓库整理。价格、平台和功能可能变化。

适合选择 Inkiva 的情况

你使用 Windows 或 macOS，希望直接在渲染后的文档中编辑，需要文件夹与多文档导航，并且重视普通 Markdown 文件周边的自动保存、本地历史和崩溃恢复。

适合选择 Typora 的情况

你希望使用成熟的商业产品 Typora，并且接受一次性购买授权。Typora 还提供 Linux 版本，而 Inkiva 当前没有 Linux 发布包。

适合选择 MarkText 的情况

你更倾向 MIT 许可证，或者需要 Linux 安装包。MarkText 是 Inkiva 的上游基础项目；Inkiva 是具有独立品牌、产品方向并采用 GPL-3.0 项目许可证的持续开发衍生项目。

需要说明的边界

Inkiva 并不宣称在所有方面优于 Typora 或 MarkText。它当前更适合希望获得文档优先的所见即所得编辑、标准 Markdown 可移植性，以及本地文档导航和恢复能力的 Windows/macOS 用户。Linux、移动端、云同步和团队协作不是当前 Inkiva 的发布目标。
