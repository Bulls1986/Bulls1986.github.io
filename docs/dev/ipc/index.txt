<p>Channel names are typed by the contract in <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>src/shared/types/ipc.ts</span></span></code></span> —
wrong channel, wrong arg arity, or wrong return shape all fail at
<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>pnpm typecheck</span></span></code></span>. See <a href="/docs/dev/typescript#ipc-contract" class="link">TYPESCRIPT.md</a> for the
TypeScript-side details.</p>
<h2 id="channel-naming">Channel naming<a class="anchor" aria-hidden tabindex="-1" href="#channel-naming">#</a></h2>
<p>Renderer↔main channels are prefixed with <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>mt::</span></span></code></span> (e.g. <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>mt::fs::stat</span></span></code></span>,
<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>mt::open-new-tab</span></span></code></span>). A small number of legacy internal channels don't
follow this convention (e.g. <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>language-changed</span></span></code></span>); new channels should
always use <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>mt::</span></span></code></span>.</p>
