<h2 id="getting-started">Getting started<a class="anchor" aria-hidden tabindex="-1" href="#getting-started">#</a></h2>
<p>Inkiva is a document-first Markdown editor. It opens ordinary CommonMark/GFM files and folders, and its preview editor keeps most Markdown punctuation out of the way while you write. When the application starts without a restored session, the welcome surface offers <strong>Recent Documents</strong>, <strong>New File</strong>, and <strong>Open file</strong>.</p>
<p><img src="/docs/assets/inkiva-default.png" alt="Inkiva welcome surface with Recent Documents, New File, and Open file"></p>
<p>The titlebar command launcher opens search for documents, headings, and commands. You can click it or press <kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>. In an empty paragraph, type <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>/</span></span></code></span> to open the quick-insert menu; choose an item to turn that paragraph into a heading, list, quote, table, or another supported block.</p>
<h2 id="interface">Interface<a class="anchor" aria-hidden tabindex="-1" href="#interface">#</a></h2>
<h3 id="sidebar">Sidebar<a class="anchor" aria-hidden tabindex="-1" href="#sidebar">#</a></h3>
<p>The optional sidebar is organized around the current document and folder:</p>
<ul>
<li><strong>Files</strong> shows the opened folder tree and its <strong>Opened Files</strong> subsection.</li>
<li><strong>Search</strong> searches the opened folder with filters for the search mode.</li>
<li><strong>Outline</strong> shows headings from the selected document.</li>
<li><strong>More → Document Info</strong> provides <strong>Backlinks</strong> and <strong>Local History</strong>.</li>
</ul>
<p>Use the sidebar controls or <strong>View → Toggle Sidebar</strong>. The default Typora shortcut is <kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>; custom keybinding styles can change it. The <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>openedFilesInSidebar</span></span></code></span> preference controls the Opened Files subsection.</p>
<p><img src="/docs/assets/inkiva-interface.png" alt="Inkiva editor with the Outline sidebar, document tab, and writing surface"></p>
<p>The Files, Search, and Document Info panels are shown below.</p>
<p><img src="/docs/assets/inkiva-files.png" alt="Inkiva Files sidebar showing a folder tree and Opened Files"></p>
<p><img src="/docs/assets/inkiva-search.png" alt="Inkiva Search sidebar for searching the opened folder"></p>
<p><img src="/docs/assets/inkiva-document-info.png" alt="Inkiva Document Info sidebar with Backlinks and Local History"></p>
<h3 id="tabs-and-split-view">Tabs and split view<a class="anchor" aria-hidden tabindex="-1" href="#tabs-and-split-view">#</a></h3>
<p>Each open document can appear in a tab. Drag tabs to reorder them, use the tab context menu for file actions, or hide the tab bar and work from the sidebar's <strong>Opened Files</strong> list. <strong>View → Split Editor</strong> opens a second document pane; use the pane controls to choose which pane is the active editor.</p>
<h3 id="quick-open-and-the-command-launcher">Quick Open and the command launcher<a class="anchor" aria-hidden tabindex="-1" href="#quick-open-and-the-command-launcher">#</a></h3>
<p><strong>Quick Open</strong> (<kbd>CmdOrCtrl</kbd>+<kbd>P</kbd>) finds Markdown files in the opened folder and already-open documents. The command launcher searches commands, headings, and documents from one place.</p>
<p><img src="/docs/assets/inkiva-command-palette.png" alt="Inkiva command launcher with document, heading, and command results"></p>
<h3 id="editor-modes">Editor modes<a class="anchor" aria-hidden tabindex="-1" href="#editor-modes">#</a></h3>
<p>Inkiva opens documents in the formatted preview editor by default. <strong>View → Source Code Mode</strong> switches to the raw Markdown editor for precise syntax editing. In the default Typora shortcut style, source mode is <kbd>CmdOrCtrl</kbd>+<kbd>/</kbd>, focus mode is <kbd>F8</kbd>, and typewriter mode is <kbd>F9</kbd>. See <a href="/docs/key-bindings/" class="link">Key bindings</a> for the preset and platform-specific tables.</p>
<h2 id="open-edit-and-save-files">Open, edit, and save files<a class="anchor" aria-hidden tabindex="-1" href="#open-edit-and-save-files">#</a></h2>
<h3 id="open-a-file">Open a file<a class="anchor" aria-hidden tabindex="-1" href="#open-a-file">#</a></h3>
<p>Choose <strong>File → Open File</strong> or press <kbd>CmdOrCtrl</kbd>+<kbd>O</kbd>. You can also pass a file path or folder to Inkiva from the <a href="/docs/cli/" class="link">command line</a>.</p>
<h3 id="open-a-folder">Open a folder<a class="anchor" aria-hidden tabindex="-1" href="#open-a-folder">#</a></h3>
<p>Choose <strong>File → Open Folder</strong> or press <kbd>CmdOrCtrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd>. The folder becomes the root for the Files panel, Quick Open, and in-folder Search.</p>
<h3 id="save-changes">Save changes<a class="anchor" aria-hidden tabindex="-1" href="#save-changes">#</a></h3>
<p>Choose <strong>File → Save</strong> or press <kbd>CmdOrCtrl</kbd>+<kbd>S</kbd>. <strong>File → Save As</strong> writes the document to a new path. Inkiva marks unsaved changes in the tab and titlebar; automatic saving is enabled by default and can be adjusted in <a href="/docs/preferences/" class="link">Preferences</a>.</p>
<h2 id="appearances">Appearances<a class="anchor" aria-hidden tabindex="-1" href="#appearances">#</a></h2>
<p>Inkiva includes <strong>Inkiva Light</strong>, <strong>Inkiva Dark</strong>, and <strong>Inkiva Paper</strong>. Choose an appearance from the <strong>Theme</strong> menu or from <strong>Preferences → Theme</strong>. Light and Dark can follow the operating system; Paper remains a manual choice. See <a href="/docs/themes/" class="link">Appearances</a>.</p>
<p><img src="/docs/assets/inkiva-dark.png" alt="Inkiva editor in the Dark appearance"></p>
<p><img src="/docs/assets/inkiva-paper.png" alt="Inkiva editor in the Paper appearance"></p>
<h2 id="preferences">Preferences<a class="anchor" aria-hidden tabindex="-1" href="#preferences">#</a></h2>
<p>Open <strong>File → Preferences</strong> or the settings control at the bottom of the sidebar. Preferences can also be edited in <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>preferences.json</span></span></code></span> in the <a href="/docs/application-data-directory/" class="link">application data directory</a>. The settings window groups general, theme, editor, and spelling options.</p>
