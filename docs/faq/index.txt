<h3 id="what-are-the-supported-platforms">What are the supported platforms?<a class="anchor" aria-hidden tabindex="-1" href="#what-are-the-supported-platforms">#</a></h3>
<p>Inkiva is a desktop application and available for:</p>
<ul>
<li>Linux x64 (tested on Debian and Red Hat based distros)</li>
<li>macOS 11 (Big Sur) or later, x64 and arm64 (Apple Silicon)</li>
<li>Windows 10 or 11, x64 and arm64</li>
</ul>
<h3 id="is-inkiva-open-source-and-free">Is Inkiva open-source and free?<a class="anchor" aria-hidden tabindex="-1" href="#is-inkiva-open-source-and-free">#</a></h3>
<p>Yes, Inkiva is licensed under the <a href="https://github.com/Bulls1986/Inkiva/blob/develop/LICENSE" class="link">GPL-3.0-or-later</a> license and completely free for everyone. The source-code is available on <a href="https://github.com/Bulls1986/Inkiva" class="link">GitHub</a>.</p>
<h3 id="can-i-use-inkiva-as-note-managementtaking-app">Can I use Inkiva as note management/taking app?<a class="anchor" aria-hidden tabindex="-1" href="#can-i-use-inkiva-as-note-managementtaking-app">#</a></h3>
<p>Inkiva is a pure markdown editor without features such as knowledge management and tags but yes, you can do this via the integrated filesystem explorer and task lists.</p>

<h3 id="i-cannot-launch-inkiva-on-linux-suid-sandbox">I cannot launch Inkiva on Linux (SUID sandbox)<a class="anchor" aria-hidden tabindex="-1" href="#i-cannot-launch-inkiva-on-linux-suid-sandbox">#</a></h3>
<blockquote>
<p><em>The SUID sandbox helper binary was found, but is not configured correctly.</em></p>
</blockquote>
<p>Normally, you should never get this error but if you disabled user namespaces, this error message may appear in the command output when launching Inkiva. To solve the issue, that Chromium cannot start the sandbox (process), you can choose one of the following steps:</p>
<ul>
<li>Enable Linux kernel user namespaces to use the preferred sandbox: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>sudo sysctl kernel.unprivileged_userns_clone=1</span></span></code></span>.</li>
<li>Set correct SUID sandbox helper binary permissions: <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>sudo chown root &#x3C;path_to_inkiva_dir>/chrome-sandbox &#x26;&#x26; sudo chmod 4755 &#x3C;path_to_inkiva_dir>/chrome-sandbox</span></span></code></span>. This is preferred if you don't want to enable user namespaces.</li>
<li>Launch Inkiva with <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>--no-sandbox</span></span></code></span> argument.</li>
