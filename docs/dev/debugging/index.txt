<h2 id="use-visual-studio-code">Use Visual Studio Code<a class="anchor" aria-hidden tabindex="-1" href="#use-visual-studio-code">#</a></h2>
<p>The most simplest way is to debug using the <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Debug Inkiva</span></span></code></span> configuration. You can set breakpoints and use the <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>debugger</span></span></code></span> statement.</p>
<p><strong>Prerequisites:</strong></p>
<ul>
<li>VS Code's built-in JavaScript debugger (no extension needed — available since VS Code 1.47)</li>
</ul>
<h2 id="use-chrome-developer-tools">Use Chrome Developer Tools<a class="anchor" aria-hidden tabindex="-1" href="#use-chrome-developer-tools">#</a></h2>
<p>You can use the built-in developer tools via <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>View -> Toggle Developer Tools</span></span></code></span> in debug mode or connect via <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>chrome://inspect</span></span></code></span> using port <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>5858</span></span></code></span> for the main process and <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>8315</span></span></code></span> for the renderer process when launched via <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>pnpm run dev</span></span></code></span>.</p>
<h3 id="debug-built-application">Debug built application<a class="anchor" aria-hidden tabindex="-1" href="#debug-built-application">#</a></h3>
<p>You can use the default Electron command-line parameters to enable debug mode as described above.</p>

<h2 id="debug-slow-startup-performance">Debug slow startup performance<a class="anchor" aria-hidden tabindex="-1" href="#debug-slow-startup-performance">#</a></h2>

Please follow the tool description for setup. Afterwards, launch the following commands in parallel (e.g. use three terminal windows and launch Inkiva last).</p>
