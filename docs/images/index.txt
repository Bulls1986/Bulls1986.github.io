<h3 id="move-to-designated-local-folder">Move to designated local folder<a class="anchor" aria-hidden tabindex="-1" href="#move-to-designated-local-folder">#</a></h3>
<p>All images are automatically copied into the specified local directory that may be relative.</p>
<p><strong>Prefer relative assets folder:</strong></p>
<p>When this option is enabled, all images are copied relative to the opened file. The root directory is used when a project is opened and no variables are used. You can specify the path via the <em>relative image folder name</em> text box and include variables like <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>${filename}</span></span></code></span> to add the file name to the relative directory. The local resource directory is used if the file is not saved.</p>
<p>Note: The assets directory name must be a valid path name and Inkiva need write access to the directory.</p>
<p>Examples for relative paths:</p>
<ul>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>assets</span></span></code></span></li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>../assets</span></span></code></span></li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>.</span></span></code></span>: current file directory</li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>assets/123</span></span></code></span></li>
<li><span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>assets_${filename}</span></span></code></span> (add the document file name)</li>
</ul>
