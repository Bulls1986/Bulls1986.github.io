<h2 id="所见即所得与源码">所见即所得与源码<a class="anchor" aria-hidden tabindex="-1" href="#所见即所得与源码">#</a></h2>
<p>Inkiva 会实时渲染标题、强调、列表、任务列表、表格、代码块和图表；底层仍是普通 Markdown 文本。使用 <strong>View → Source Code Mode</strong> 可以检查精确语法。切换视图不应无故改写文档内容。</p>
<p>选中文字后通过 <strong>Format</strong> 菜单处理加粗、斜体、行内代码和链接。空段落输入 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>/</span></span></code></span> 可打开快速插入，插入标题、列表、引用、表格、代码块、数学公式等。</p>
<h2 id="markdown-表格">Markdown 表格<a class="anchor" aria-hidden tabindex="-1" href="#markdown-表格">#</a></h2>
<p>通过快速插入或 <strong>Paragraph → Table</strong> 创建表格。在单元格内编辑文本，使用表格菜单明确添加、删除行列，或调整对齐。表格不是电子表格；删除选中内容并不等于删除表格结构。</p>
<p>需要单元格内硬换行时使用 <strong>Shift+Enter</strong>，保存的 Markdown 使用 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>&#x3C;br></span></span></code></span>。Undo/Redo 与源码往返应保持可预测。</p>
<p><img src="/docs/assets/inkiva-table-context.png" alt="Windows v0.6.0 英文界面的表格右键菜单实机截图"></p>
<p><img src="/docs/assets/inkiva-table-hardbreak.png" alt="Windows v0.6.0 表格单元格硬换行保存后重开的实机截图"></p>
<p>实测文件保存后包含 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Alpha&#x3C;br>Line 2</span></span></code></span>，应用关闭并重新打开后仍能正确呈现。</p>
<h2 id="标准文档链接">标准文档链接<a class="anchor" aria-hidden tabindex="-1" href="#标准文档链接">#</a></h2>
<p>选中文字按 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Ctrl+K</span></span></code></span>（Windows）或 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>Command+K</span></span></code></span>（macOS），在现有链接对话框中输入目标或选择工作区候选文件。候选项通过相对路径区分同名文档；取消不会写入隐藏改动，一次插入对应一次 Undo。</p>
<p>普通点击是编辑操作；使用修饰键单击或显式 Jump 动作才会跟随链接。示例：<span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>[计划](./plan.md#milestones)</span></span></code></span>。</p>
<h2 id="反向链接断链和重命名">反向链接、断链和重命名<a class="anchor" aria-hidden tabindex="-1" href="#反向链接断链和重命名">#</a></h2>
<p>在 <strong>More → Document Info</strong> 查看反向链接和断链报告。对断链点击条目可定位源文本（辅助功能名 <strong>Locate source occurrence</strong>，不是独立的 Locate 文字按钮），再点击 <strong>Repair</strong> 打开 <strong>Insert link</strong> 对话框；取消不改写原文档，确认后按正常链接编辑和 Undo 处理。外部 URL、图片资源和缺失标题片段不等同于该工作区断链检测范围。</p>
<p>移动或重命名文件后，如果提示更新引用，先查看影响范围，再选择 <strong>Update / Keep unchanged / Cancel</strong>。取消引用修复不代表撤销已完成的文件移动；跨文件操作出现部分成功时，应检查恢复记录。</p>
<h2 id="图片与恢复">图片与恢复<a class="anchor" aria-hidden tabindex="-1" href="#图片与恢复">#</a></h2>
<p>可粘贴、拖入或插入图片；选中图片后可调整替代文本、路径、大小，缺图时可使用 <strong>Choose Image</strong> 重新选择文件。失败的异步导入不应永久留下 <span data-rehype-pretty-code-figure=""><code data-language="plaintext" data-theme="github-dark-dimmed github-light" class="inline"><span data-line=""><span>loading-*</span></span></code></span> 占位符。</p>
